Records hands + body pose + face in one pass. Same keys and export format as the original tool, with extra fields added. Use this for signs the avatar must perform, and for any sign where arm position matters.

Capture

Use clips, not snapshots. The recogniser reads ~3 seconds of motion; a single frame carries none and gets dropped at training time. Snapshot is kept only for quick checks.
